# Передаточный комплект: движок ленточных композиций → configurator.vargov.ru

Комплект для интеграции наработок в подготовленный конфигуратор
https://configurator.vargov.ru/. Передаются два файла:

- **`index.html`** — самодостаточный движок с интерфейсом: генерация,
  3D-просмотр, расчёт, экспорт. Один файл ~340 КБ, без внешних
  зависимостей, без сборки, без сервера — открывается локально и работает.
- **`INTEGRATION.md`** — этот документ.

Ветка с историей и замерами: `claude/ribbon-glass-rod-configurator-xgxdrc`
(каждый коммит — с числами «до/после»). Подробное описание алгоритмов —
в `README.md` рядом.

## 1. Способы интеграции (от простого к глубокому)

### A. iframe + postMessage-мост (рекомендуется)

`index.html` кладётся на поддомен/путь и встраивается iframe'ом.
В файл встроен мост: родительская страница управляет генерацией и
получает результаты сообщениями. Ваш UI (поля, кнопки, корзина) — ваш;
наш движок — просмотр и генерация.

Протокол (все сообщения — объекты с полем `type`):

| Команда → iframe | Поля | Действие |
|---|---|---|
| `vargov:apply` | `params:{w,d,h,c, plast:"mix"\|"edge", form, rows:1\|2, rod, rodD:8\|10, seed, leds:bool, cables:bool, color, frame}` | выставить параметры и собрать вариант |
| `vargov:regen` | — | следующий вариант (шаг зерна) |
| `vargov:variant` | — | запросить текущее состояние |
| `vargov:spec` | — | запросить спецификацию объектом |

| Ответ ← iframe | Поля |
|---|---|
| `vargov:ready` | страница загрузилась и собрала первый вариант |
| `vargov:built` | `variant` (см. §3), `lenM` (пог. м), `box`, `rods` (шт), `ok` |
| `vargov:variant` | `variant` |
| `vargov:spec` | `spec` (та же структура, что CSV «Для производства») |
| `vargov:error` | `error` (строка) |

Пример родительской страницы:

```html
<iframe id="vg" src="/engine/index.html" style="width:100%;height:720px;border:0"></iframe>
<script>
const vg = document.getElementById('vg').contentWindow;
window.addEventListener('message', (e)=>{
  if(!e.data || typeof e.data.type!=='string') return;
  if(e.data.type==='vargov:ready')
    vg.postMessage({type:'vargov:apply', params:{
      w:2400, d:900, h:800, c:600, plast:'mix', rows:2,
      rod:150, rodD:10, seed:2308378654}}, '*');
  if(e.data.type==='vargov:built')
    console.log('вариант №'+e.data.variant.v, e.data.lenM+' пог. м');
});
</script>
```

Все сборки асинхронные; ответ `vargov:built` приходит по завершении.
Индикатор прогресса в процентах движок показывает сам.

### B. Как отдельная страница

Файл просто кладётся на поддомен (например, `lenta.vargov.ru`) и
связывается ссылкой из основного конфигуратора. «Ссылка на вариант»
(§3) позволяет передавать выбранный вариант между страницами и
менеджеру/клиенту.

### C. Перенос движка в ваш код (не рекомендуется без согласования)

Генерация, починки и правила производства переплетены в одном конвейере
(лестница вариантов → разведение касаний → финальные проходы → ворота
качества). Вырезать «только генератор» без потери гарантий качества
нельзя; если нужен именно перенос — договоримся о выделении модуля
отдельной задачей.

## 2. JS-API (для интеграции на одной странице)

`window.__vargov` внутри `index.html`:

- `apply({dimW,dimD,dimH,rows,rWidth,rodD,...})` → `Promise` — выставить
  поля и собрать; ключи совпадают с id полей интерфейса;
- `regen()` → `Promise` — следующий вариант;
- `bbox()` — габарит факта, метраж `lenM`, число стержней;
- `spec()` — спецификация (объект);
- `clearance()` — контроль качества: касания, минимальные зазоры и радиусы;
- `raw()` — вся сцена (ленты: `centers/railA/railB/rods/leds/cabs...`).

## 3. Вариант и воспроизводимость

Вариант целиком описывается компактным объектом (он же — hash «Ссылки
на вариант» и записи «Избранного»):

```
{v: <номер варианта>, w,d,h,c, pl, f, r, rw, rd,
 fr, frc, col, op, op2, g, gc}
```

Диоды и тросы в объект варианта не входят — это чекбоксы интерфейса;
через мост они выставляются полями `leds`/`cables` команды `vargov:apply`.

Один и тот же `v` при тех же параметрах даёт **бит-в-бит ту же
композицию на любой машине** — генерация детерминирована, таймеров в
геометрии нет. Номер на экране — именно корневое зерно.

## 4. Экспорт «Для производства»

Кнопки в интерфейсе (и те же данные через `spec()`):

- **CSV** — спецификация: метраж, трубки по цветам, диоды, тросы с
  нагрузками, вес, мощность;
- **OBJ** — геометрия для 3D-пакетов;
- **DXF** — линии каркаса;
- **Выкройка** — развёртка каркаса 1:1 для печати (станции, диоды, тросы).

## 5. Правила производства, зашитые в генератор

- Лента — **всегда один непрерывный отрезок**; форму заполняет змейкой
  по ширине/глубине/высоте (без соединений).
- Метраж — **не меньше 2 пог. м на метр главного габарита** (можно больше).
- Трубки Ø8/Ø10, стенка 1.5 мм, длины 100–350; торец не доходит до
  каркаса 6 мм; трубки стоят почти вплотную (штатный зазор 1.6 мм),
  локальные расхождения **не больше 5 мм между стёклами**.
- Каркас Ø3 (золото/хром), **без острых углов — везде плавно**;
  самопересечения запрещены; между дальними участками ≥ Ø трубки + 11 мм.
- Двурядная: 3 контура, центральный независим (подъём/провис до 150 мм);
  ряды могут наклоняться друг к другу по горизонтали и вертикали.
  Однорядная: наклон ряда к каркасу ≤ 20°; стержень от 200 мм.
- Диоды 0.1 Вт / 3 В каждые 100 мм на центральном контуре (у 1р — на
  канте); тросы — по физике пролётов и на концах ленты; провис под весом.
- Минимумы габаритов: «Волны» 1500×600×600 (высота ≤ 3500),
  «Спираль» 1000×1000×600; максимум полей 20000.

## 6. Известные ограничения (в работе)

- Крайне вытянутые «Волны» (ширина > ~5000 при глубине 900) пока
  недобирают метраж одним отрезком (5400 даёт ~6.4 при норме 10.8);
  4400 — 8.06 при норме 8.8 (92%).
- «Спираль» (на ребро): формы и гироскоп стабильны и чисты по всем
  веерным метрикам.

## 7. Контроль качества при приёмке интеграции

После встраивания прогоните на своей стороне:
`__vargov.clearance()` → `collisions` должно быть 0; `bbox().lenM` ≥
2×(главный габарит, м); визуально — гребёнка без пропусков (правило
5 мм), каркас без острых углов. Тестовые варианты для сверки:
`{w:2400,d:900,h:800,rows:2,rod:150,seed:2308378654}` → 5.67 пог. м;
`{w:2600,d:2200,h:800,...,seed:1550467706}` → 10.14; 
`{w:2400,d:600,h:1400,...,seed:1550467706}` → 7.71.
