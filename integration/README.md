# Пакет данных для интеграции в сайт

Готовые тексты на восьми языках в машиночитаемом виде. Собраны из `content/` скриптом, вручную не редактируются.

Языки: `ru`, `en`, `de`, `fr`, `it`, `es`, `vi`, `ar`.

| Файл | Содержимое | Объём |
|---|---|---|
| `products.json` | Тексты карточек товаров | 605 артикулов × 8 языков = 4840 текстов |
| `journal.json` | Статьи раздела «Прямая речь» | 22 статьи × 8 языков = 176 текстов |

## Что уже есть на сайте, а чего нет

| Раздел | На сайте сейчас | В пакете |
|---|---|---|
| Журнал | ru, en, de, fr, it, es | все 8 — **vi и ar новые** |
| Карточки товаров | требует проверки в коде | все 8 |

Тексты `en`, `de`, `fr`, `it`, `es` для журнала сняты с работающего сайта — они уже опубликованы и включены в пакет, чтобы он был единым источником правды и чтобы можно было сверить расхождения. Переводы `vi` и `ar` — новые, на сайте их нет.

## `products.json`

```json
{
  "meta": { "kind": "product-descriptions", "locales": ["ru", "..."], "skuCount": 605 },
  "items": {
    "LC0138": {
      "ru": {
        "type": "Световая композиция",
        "awardWinning": false,
        "paragraphs": ["первый абзац…", "второй абзац…"],
        "whereItWorks": "Парадные пространства — холлы…",
        "style": "Современная классика с ар-деко-нотой…",
        "madeToOrder": "Число веретён, глубина каскада… — индивидуально, на заказ.",
        "labels": { "whereItWorks": "Где уместна.", "style": "Стилистика." },
        "sourceFile": "batch-LC0122-LC0136.md"
      },
      "ar": { "…": "…" }
    }
  }
}
```

Пояснения к полям:

- **`type`** — тип изделия на языке локали («Световая композиция», «Light composition», «تركيبة ضوئية»). Используется в заголовке карточки.
- **`awardWinning`** — стоит ли отметка международной награды. Отметка есть у части артикулов; на сайте её нужно выводить только там, где `true`.
- **`paragraphs`** — тело текста по абзацам, **порядок значим**. Абзац про смену дня и вечера может стоять в середине, в конце или внутри первого — так задумано автором, менять порядок нельзя.
- **`whereItWorks`** / **`style`** — содержимое двух смысловых блоков без метки.
- **`labels`** — сами метки блоков на языке локали. Вынесены отдельно, чтобы вёрстка могла оформить их как подзаголовки. В арабском метка меняется по роду изделия: `أين تليق.` для женского, `أين يليق.` для мужского — поэтому её нельзя захардкодить, надо брать из данных.
- **`madeToOrder`** — финальная строка про изготовление на заказ. Всегда последняя.
- **`sourceFile`** — из какого файла собрано, для отладки.

## `journal.json`

```json
{
  "meta": { "kind": "journal", "locales": ["ru", "..."], "articleCount": 22 },
  "articles": {
    "dizain-kod": {
      "ru": {
        "title": "Дизайн-код Vargov®Design",
        "category": "Философия",
        "date": "15 мая 2026",
        "lead": "В основе бренда — не визуальный стиль…",
        "body": ["абзац", "абзац", "…"]
      }
    }
  }
}
```

- **`title`** — заголовок статьи.
- **`category`** — рубрика, локализована («Философия», «Philosophy», «Triết lý», «الفلسفة»).
- **`date`** — дата в формате, принятом для языка. Хранится строкой, а не датой, потому что на сайте она уже отображается локализованной. Если понадобится сортировка — брать порядок из русской версии или добавить машинное поле отдельно.
- **`lead`** — короткое описание под заголовком, оно же идёт в `<meta name="description">`.
- **`body`** — тело статьи по абзацам, порядок значим.

Slug статьи совпадает с адресом на сайте: `dizain-kod` → `/journal/dizain-kod`.

## Что нужно сделать в коде сайта

1. Добавить `vi` и `ar` в список локалей.
2. Завести маршруты `/vi/journal/*` и `/ar/journal/*`.
3. Для арабского выставить `dir="rtl"` на корневом элементе и проверить вёрстку: зеркальные отступы, выравнивание, направление стрелок навигации.
4. Добавить оба языка в переключатель языков и в `hreflang`.
5. Проверить, все ли восемь языков подключены для карточек товаров, и подставить недостающие из `products.json`.

## Как пересобрать пакет

Данные генерируются из `content/`, поэтому при правках текстов пакет надо пересобрать, а не редактировать руками. Скрипт сборки приложен рядом: `build-bundles.py`.

```bash
python3 integration/build-bundles.py
```

## Проверено

Собранные пакеты прошли независимую проверку по пяти срезам: обратная сборка текста из JSON и сверка с исходником, пересчёт полноты, кодировка и спецсимволы, сохранность фактов между языками, пригодность схемы. Результаты — в `integration/VERIFICATION.md`.
