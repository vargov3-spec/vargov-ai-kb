# Пакет данных для интеграции в сайт

Готовые тексты на восьми языках в машиночитаемом виде. Собираются из `content/` скриптом `build-bundles.py`, вручную не редактируются.

Языки: `ru`, `en`, `de`, `fr`, `it`, `es`, `vi`, `ar`. Схема версии 2.

| Файл | Содержимое | Размер |
|---|---|---|
| `products.json` | Карточки товаров, все языки | 605 артикулов × 8 = 4840 текстов, 8,5 МБ |
| `by-locale/products.<lang>.json` | То же, по одному языку | 0,9–1,2 МБ каждый |
| `journal.json` | Статьи «Прямой речи», все языки | 22 статьи × 8 = 176 текстов |

**Для страниц сайта берите поязычные файлы.** Странице товара нужно около 1,6 КБ; если импортировать общий `products.json`, в граф модулей уедет 8 МБ, а при попадании в клиентский компонент — и в браузер.

## Что уже на сайте, а чего нет

| Раздел | Сейчас на сайте | В пакете |
|---|---|---|
| Журнал | ru, en, de, fr, it, es | все 8 — **vi и ar новые** |
| Карточки товаров | требует проверки в коде | все 8 |

Тексты `en`, `de`, `fr`, `it`, `es` для журнала сняты с работающего сайта: они уже опубликованы и включены, чтобы пакет был единым источником правды и чтобы можно было увидеть расхождения. `vi` и `ar` — новые переводы.

## `products.json`

```json
{
  "meta": { "schemaVersion": 2, "locales": ["ru","…"], "rtlLocales": ["ar"],
            "skuCount": 605, "checksum": "…", "generated": "2026-08-09T12:47:00+00:00" },
  "items": {
    "LC0138": {
      "ru": {
        "type": "Световая композиция",
        "awardWinning": false,
        "awardFormat": null,
        "paragraphs": ["первый абзац…", "второй абзац…"],
        "whereItWorks": "Парадные пространства — холлы…",
        "style": "Современная классика с ар-деко-нотой…",
        "madeToOrder": "Число веретён… — индивидуально, на заказ.",
        "labels": { "whereItWorks": "Где уместна", "style": "Стилистика" },
        "sourceFile": "content/product-descriptions/batch-LC0122-LC0136.md"
      }
    }
  }
}
```

- **`type`** — тип изделия на языке локали, идёт в заголовок карточки.
- **`awardWinning`** — есть ли отметка международной награды (у 24 артикулов). **`awardFormat`** хранит, как она оформлена в исходнике: `dot` (через `·`) или `paren` (в скобках).
- **`paragraphs`** — тело по абзацам, **порядок значим**. Абзац про смену дня и вечера может стоять в середине, в конце или внутри первого — так задумано автором.
- **`whereItWorks`** / **`style`** — содержимое двух смысловых блоков.
- **`labels`** — подписи этих блоков на языке локали, **без завершающей точки**, готовы для `<h3>`. Вынесены в данные, потому что меняются по роду изделия: в русском 4 варианта («Где уместна / уместен / уместно / уместны»), во французском 3, в арабском 2 (`أين تليق` / `أين يليق`). Захардкодить нельзя.
- **`madeToOrder`** — финальная строка про изготовление на заказ, всегда последняя.
- **`sourceFile`** — путь от корня репозитория, для отладки.

## `journal.json`

```json
{
  "meta": { "schemaVersion": 2, "articleCount": 22, "…": "…" },
  "articleMeta": {
    "dizain-kod": { "dateISO": "2026-05-15", "categoryId": "philosophy" }
  },
  "articles": {
    "dizain-kod": {
      "ru": {
        "title": "Дизайн-код Vargov®Design",
        "category": "Философия",
        "date": "15 мая 2026",
        "lead": "В основе бренда — не визуальный стиль…",
        "body": [
          { "type": "p",  "text": "обычный абзац" },
          { "type": "h",  "text": "Плюсы" },
          { "type": "li", "text": "пункт списка" }
        ],
        "metaLabels": { "category": "Рубрика", "date": "Дата" }
      }
    }
  }
}
```

- **`articleMeta`** — общие для всех языков машинные поля: `dateISO` для сортировки ленты, `<time dateTime>`, JSON-LD и sitemap; `categoryId` — устойчивый код рубрики (`philosophy`, `installation`, `recognition` и ещё 7) для фильтров и адресов вида `/journal/category/…`. Локализованные названия остаются в самих статьях для показа.
- **`body`** — типизированные блоки, а не плоские строки: `p` — абзац, `h` — подзаголовок раздела, `li` — пункт списка. Маркеры разметки уже сняты. Верстать так: `li` собирать в `<ul>`, `h` — в подзаголовок, `p` — в `<p>`.
- **`lead`** — короткое описание под заголовком, оно же в `<meta name="description">`.
- **`metaLabels`** — подписи «Рубрика»/«Дата» на языке локали, если понадобятся в вёрстке.

Slug совпадает с адресом: `dizain-kod` → `/journal/dizain-kod`.

## Что нужно сделать в коде сайта

1. Добавить `vi` и `ar` в список локалей.
2. Завести маршруты `/vi/journal/*` и `/ar/journal/*`.
3. Для арабского выставить `dir="rtl"` (список RTL-локалей есть в `meta.rtlLocales`) и проверить вёрстку: зеркальные отступы, выравнивание, направление стрелок навигации.
4. Добавить оба языка в переключатель языков и в `hreflang`.
5. Проверить, все ли восемь языков подключены для карточек товаров, и подставить недостающие.

## Пересборка

```bash
python3 integration/build-bundles.py
```

Скрипт падает с ненулевым кодом, если хоть одна карточка или статья не разобралась, — так что молча битый пакет не соберётся. `meta.checksum` годится как ключ кэша.

## Проверка качества

Пакеты прошли независимую проверку по пяти срезам. Итог и остаточные замечания — в `VERIFICATION.md`.
