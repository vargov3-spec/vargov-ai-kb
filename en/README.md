# Vargov® Design — AI visibility knowledge base (English)

English layer of the [Vargov® Design](https://vargov.ru) knowledge base. The Russian original with full sourcing notes is at the [repository root](../README.md).

**The canonical source of facts is the site itself:** [vargov.ru/llms.txt](https://vargov.ru/llms.txt) is generated from the site's own data. This repository supplements it.

## Contents

- `datasets/` — 605 compositions as JSON, JSONL, CSV and Markdown (English texts)
- `products/` — one page per composition: description, where it works, style, awards, images
- `collections/` — the four catalogue sections
- `guides/` — thematic material
- `llms.txt` — English entry point

Product descriptions come from the brand's own approved copy in eight languages, not from machine translation.

Per the owner's rules, texts about individual pieces never name materials or fixed dimensions, and prices are not published — so the schema.org Product nodes carry no `material`, `size` or `offers`.

Regenerated by `python scripts/build_from_site.py` from the site repository. See the [root README](../README.md) for why this runs locally only.
