# Installation and connection scenarios

Category: Installation · Date: 2 October 2024 · Slug: stsenarii-montazha

The optimal installation scenario balances aesthetics, ease of maintenance and the technical requirements of the composition and the interior.

The best installation scenario is a balance between aesthetics, ease of maintenance and the technical requirements of the particular lighting composition and interior.

The installation scenario for Vargov®Design lighting compositions has to be detailed and consistent so that the assembly stays precise. Here are the main steps:

1. Checking the delivery

- On delivery, check the crates for damage.

- The top of the crate is marked with the branded tape.

- Find the crate holding the installation drawing (printed on banner fabric at 1:1 scale).

2. Preparing the surface

- Make sure the ceiling is prepared: it may be plasterboard with plywood backing, it may have a metal base or a dedicated Vargov®Design base plate made together with the composition.

- The ceiling must have a service opening for connecting the composition and for placing the driver in the void above the ceiling or in the distribution board.

3. Fitting the wires and suspension cables

The tag on a wire or cable performs several important functions during the installation of a Vargov®Design lighting composition:

- Identifying the elements

Every tag carries a unique number matching a specific position on the installation drawing. This makes it quick and precise to tell where a given wire or cable belongs.

- Height stop

The tag also acts as a height stop for each element. During installation it must come to rest against the ceiling fixing, which puts the elements of the composition in the correct position and alignment.

- A simpler installation

The tags make the job considerably simpler, letting fitters work faster and avoid mistakes. Since every wire and cable is already marked, the fitter can follow the drawing without any confusion.

4. Connecting to the mains

For 12 V LEDs:

- Allow space for the driver in the distribution board.

- Run low-voltage wires from the board to the location of the composition, one per element.

- Reinforce the ceiling with plywood, drill the holes according to the installation drawing and pull the wires through.

- Join the wires to the elements of the composition using the connectors supplied.

For 220 V LEDs:

- Run a 220 V cable to the installation point and split it out to the number of elements.

- Reinforce the ceiling with plywood, drill the holes and pull the wires through.

- The connection is made through the dedicated terminal blocks supplied.

5. Connection options

- If the ceiling is already prepared and there is a single 220 V outlet, you can:

- Use the base plate of the composition, which houses all the connections and drivers (base height from 80 mm).

- Use an inspection hatch for the connection and place the driver in the void above the ceiling.

6. Points to allow for

- For 12–24 V LEDs: space has to be allowed for the driver in the distribution board or in the void above the ceiling, with an access hatch.

- For 220 V LEDs: direct connection to the mains, no driver.

7. Safety

- Before starting work, make sure the supply line is switched off, to rule out short circuits or electric shock.

- Use only good-quality terminal blocks, heat-shrink tubing and other connection materials, to rule out any risk of fire or damage.

How to choose a scenario:

- If future access to the system is critical (on large projects, for instance), use an inspection hatch. It keeps the technical parts easy to reach for servicing.

- For minimalist interiors and low ceilings, mounting straight onto the plywood backing without a base plate is the best choice: it saves height and keeps the design clean.

- On projects with high ceilings, a base plate makes installation and servicing simpler — it conceals all the technical parts and simplifies the connection.
