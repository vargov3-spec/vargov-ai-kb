# Production spec: what the configurator fills in, and what is left to the person

Category: Production · Date: October 25, 2026 · Slug: tz-na-proizvodstvo

The production spec is put together right on the website: any visitor can open the blank form — no sign-in, no account. Here is what a person gets straight away, and what arrives only once the spec is released to production.

The page vargov.ru/specifications assembles the production spec — the document a composition is manufactured from and, for some compositions, the document the ceiling is marked out from as well. Any visitor can open the blank form: no sign-in, no registration and no account are needed, and none of them exist.

Why it matters to the client and the architect

A production spec is not an inquiry, not an order and not a quote: there is no price in it and there cannot be one. It is a summary of everything that goes into production: the SKUs of the compositions, their parameters, the layout, the colors. For the client it is a chance to check and confirm the design once, instead of having to restate it in correspondence. For the architect it is a PDF of the spec that can be attached to the project, plus a keyed link for opening the spec, adding to it and confirming it.

How it gets filled in

There are two routes. If the composition has already been built in the configurator, its link is pasted into the first step of the spec and the fields fill themselves in: SKU, dimensions, colors, layout. The configurator itself has a button for this — “Заполнить ТЗ” (Fill in the spec). If the composition has not been built yet, the spec is filled in step by step, starting with the SKU; wherever a parameter is still unknown, there is a button marked “Уточню позже” (I’ll specify later). The only mandatory field is “Объект” (Project) — “Restaurant, Moscow”, for instance. A name and contact details are optional; if the person enters them, a consent checkbox for data processing appears.

A keyed link instead of an account

Pressing “Сохранить данные” (Save data) gives the person their own keyed link. That link is how the spec is opened, added to and confirmed. There is no account area — everything rests on this link, and the key stays with the person: if the link is lost, only a manager can recover the spec. Until the manager releases the spec to production it can still be edited, and every edit changes what will later come out in print.

What is available immediately

Saving opens the “3D-конфигурация” (3D configuration) page right away: for every composition there is a configurator 3D window, with the composition’s parameters below it. This is a view on screen, not a file; there is a full-screen mode and AR on iPhone. The PDF of the spec itself is available immediately too, through the “PDF RU” and “PDF EN” buttons: that one is a file — it opens in a new tab and downloads. Below the 3D window, once the window has assembled the composition, a button appears for exporting the 3D model as FBX for 3ds Max.

The 1:1 installation plan, and why it comes later

The ceiling marking plan is a separate PDF, and it becomes available only after the manager releases the spec to production; until then the button is inactive and says so outright: “Станет доступна после запуска в производство” (Available once the spec is released to production). The reason is simple: while the spec is still being edited the markings change with it, and there is no point printing markings that will be different tomorrow. The file holds four versions: a plotter sheet and A4 sheets, each of them for the ceiling and for the floor. Print at exactly 100%, with no “вписать в страницу” (fit to page); the sheet carries a 100 mm segment so the scale can be checked with a ruler. The plotter sheet comes as a single piece with sides of up to 5 m; a plan larger than 5 m is cut into parts, and A4 sheets are joined along the marks. This is a 1:1 sheet for printing — how true the scale is depends on how it was printed, so the control segment is worth measuring before work begins.

Where the limits are

A spec can be created only for the compositions the configurator calculates in full: 360 of 605 as of October 25, 2026. An SKU that is not ours cannot be entered in the field — a red line appears instead: “рассчитывается индивидуально” (calculated individually); SKUs like that are not part of those 360 at all, because the configurator does not calculate them. Of those 360, 345 have the 1:1 installation plan. Ten ribbons do not: a ribbon has no cloud of elements, it is built on a different principle altogether. Four compositions on a frame do not either: their elements hang on the frame rather than from the ceiling, so the number of suspension lines running to the ceiling is zero. And one ready scene does not — the LC0406-1 wall sconce: its composition comes ready-made rather than calculated, there is no layout, and with no layout there is nothing to mark out on the ceiling. One more case belongs to the individual spec rather than to the SKU: if installation on a metal base is chosen in it, the 1:1 plan is not issued, because that kind of mounting does not need one — and that holds for any SKU, whichever one it is. The page exists in two languages — vargov.ru/specifications and vargov.ru/en/specifications — and there are no other language versions. It is closed to search engines and no other page of the site links to it: the only way in is a direct link, from a post or from the configurator.
