# Тексты карточек товара vargov.ru

Полный комплект описаний для каталога: **594 текста**, все артикулы сайта от LC0001 до LC0602.

## Как это сделано

- Стилевой эталон: 114 текстов с luxuriti.ru (`datasets/luxuriti-texts.json`)
- Источник изображений: только галереи vargov.ru (по 2-4 фото на артикул — общий вид, деталь, варианты отделки, интерьер)
- Текст описывает не одно фото, а возможную композицию из таких элементов — художественный образ, материалы и фактуры, поведение света днём и вечером, уместные помещения
- Концовка каждого текста индивидуальна и сообщает, что размер, форма и число элементов — на заказ
- Товары не-светильники (панно, перегородки, скульптуры, биокамины, зеркала, торшеры, занавесы) описаны по фактическому назначению
- Отметка Award Winning на фирменных фото упоминается в тексте
