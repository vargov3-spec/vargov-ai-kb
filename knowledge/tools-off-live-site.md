# Инструменты переведены с живого сайта на локальные данные

Сделано 10.09.2026 по общему правилу, принятому втроём: **инструмент не ходит на живой
сайт за данными, которые лежат в репозитории.** Не из вежливости, а потому что живой сайт
отдаёт то, что отдаёт сегодня, а репозиторий версионируется.

Оба инструмента искали на vargov.ru тильдовскую разметку, которой там нет с редизайна:
ходили вхолостую и при этом засоряли статистику сайта собственными обходами.

## guardian — эталонный каталог для поиска копий

`V:\защита контента\guardian`

- `build_reference.py` — **помечен устаревшим, не запускать**. Разбирал
  `sitemap-store.xml` и `var product = {...}`.
- `build_reference_local.py` — **новый**. Читает `catalog.generated.json` из репозитория
  сайта, сеть не используется вовсе. Тот же результат: `products` в SQLite и
  `reference/reference_index.jsonl`.

Прогон 10.09.2026: добавлено 6, пропущено 599, **товаров в базе стало 605** (было 599).
Ключи: `--limit N` проба, `--catalog <путь>` другой источник, `--refresh` обновить
уже собранные.

Ежедневный мониторинг (`vargov-daily-monitor`) этот скрипт не вызывает — он запускает
`adapters.py`, `pipeline.py`, `comments.py`. Так что обхода сайта по расписанию не было
и нет.

## Генератор коммерческих предложений

`V:\Vargov Design в ИИ\proposal-generator`

- `src/siteData.ts` — **новый модуль**: собирает `ProductData` по артикулу из
  `catalog.generated.json` и `product-copy/products.ru.json`. Путь переопределяется
  переменной окружения `VARGOV_SITE_DATA`.
- `src/scrape.ts` — `getProduct` теперь **сначала** берёт данные из репозитория сайта
  и только при его отсутствии падает на прежний путь (Playwright по живой странице).

Проверка на LC0577: 15 кадров галереи, ссылка на 3D, описание 850 знаков, источник
`local-dataset`, ни одного сетевого запроса. `npx tsc --noEmit` — чисто.

## Что осталось

Прежний путь в `scrape.ts` не удалён намеренно: он срабатывает, если репозитория сайта
нет под рукой (облачная выкладка генератора). Но тильдовскую разметку он уже не найдёт,
так что при отсутствии репозитория генератор честно скажет, что данных нет, вместо того
чтобы выдумать их.
