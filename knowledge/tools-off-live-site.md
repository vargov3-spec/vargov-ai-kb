# Инструменты не ходят на живой сайт за данными, которые лежат в репозитории

Правило принято 10.09.2026: **инструмент не ходит на живой сайт за данными, которые
лежат в репозитории.** Живой сайт отдаёт то, что отдаёт сегодня, а репозиторий
версионируется; к тому же собственные обходы засоряют статистику сайта.

По этому правилу внутренние инструменты бренда (сверка каталога, генератор
коммерческих предложений) с 10.09.2026 берут данные о композициях из репозитория
сайта, а не со страниц vargov.ru. База знаний собирается так же — локально, из
данных репозитория сайта (`scripts/build_from_site.py`).
