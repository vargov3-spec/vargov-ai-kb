# Как заполнить реальные характеристики топ-товаров

> **Важно, прочесть до заполнения (обновлено 2026-09-04).** Правило владельца: в
> текстах о конкретных изделиях **не называются материалы и размеры**, цены не
> публикуются. Поэтому собранные здесь характеристики **не идут на карточки
> сайта** — они нужны для внутренних датасетов, анкет премий и ответов на
> запросы архитекторов. В публичных материалах бренда (сайт, llms.txt,
> schema.org, PR) их не используем.
>
> Изменился и контекст: на новом сайте у всех 605 композиций есть авторские
> описания на восьми языках, согласованные владельцем. Прежняя формулировка
> «93% карточек без описаний» относилась к сайту на Tilda и больше не верна.
> Незакрытым остаётся именно технический слой: материал, габариты, температура
> света, мощность — их на карточках нет намеренно.

Файл: [specs-intake-priority.csv](specs-intake-priority.csv) — 45 приоритетных позиций (составлен в июле по каталогу Tilda; артикулы актуальны, адреса карточек в нём — старые, канонические см. в [datasets/products.json](../datasets/products.json)), отобранных не случайно:

1. **4 награждённых SKU** (LC0217 — Interlight Russia · Российский светодизайн 2022, LC0236 — IDA 2022, LC0342 — ADD Awards 2023, LC0343 — NYPDA 2023 / BLT 2023) — подтверждены страницами премий; авторские описания на сайте у них есть, нет только технического слоя. Наибольший эффект: у этих товаров уже есть внешний авторитет, не хватает только глубины данных.
2. **41 товар шоурума** — на прежнем (Tilda) сайте у них были частичные характеристики (размер, материал, диоды); на новом сайте технического слоя нет по решению владельца, данные собираются только во внутренний датасет.

## Что нужно заполнить
Для каждой строки — колонки `material`, `dimensions`, `color`, `light_temperature`, `wattage_voltage`, `weight_kg`. Можно оставлять пустыми, если параметр неприменим (например, у товара без подсветки).

## Что произойдёт дальше
После заполнения — пришлите файл обратно, и я:
1. Положу данные во внутренний (непубличный) датасет вне репозитория.
2. Использую их для анкет премий и ответов архитекторам. В `products/`, `datasets/products.json` и `references/catalog.jsonld` материалы, размеры и мощность **не вносятся** (правило владельца); файла `references/schema-products.jsonld` в репозитории больше нет — граф Product-узлов теперь `references/catalog.jsonld`.
3. Отмечу в отчёте, что для этих SKU данные подтверждены брендом напрямую (не только с сайта).

Это не разовая акция — можно повторять для следующих партий по 40-50 товаров, постепенно закрывая пробел по всему каталогу.
