## Где именно на сервере искать

Работающему Next.js нужны исходники и сборка `.next`, поэтому на сервере они точно есть. Типовые места: `/var/www/*`, `/home/*/`, `/opt/*`, `/srv/*`.

Быстрее всего — спросить у nginx, куда он проксирует `vargov.ru`.

## Как найти за пять минут (без SSH-ключей)

Timeweb Cloud даёт консоль прямо в панели управления: **timeweb.cloud → Облачные серверы → ваш сервер → Консоль**. Логин `root` и пароль сервера. Дальше по порядку:

```bash
# 1. Куда nginx отправляет запросы vargov.ru
grep -rE "server_name|proxy_pass|root" /etc/nginx/sites-enabled/ | grep -A2 -B2 vargov

# 2. Какой процесс слушает порт из proxy_pass (обычно 3000)
ss -tlnp | grep -E "3000|3001|8080"

# 3. Найти сам проект Next.js
find / -name "next.config.*" -not -path "*/node_modules/*" 2>/dev/null

# 4. Как он запускается
systemctl list-units --type=service | grep -iE "next|node|vargov"
pm2 list 2>/dev/null
```

Команда №3 обычно сразу выдаёт путь вида `/var/www/vargov-site/next.config.js`. Это и есть корень проекта.

## Что сделать, когда путь найден

```bash
cd <путь к проекту>
git remote -v          # есть ли уже удалённый репозиторий
git log --oneline -5   # есть ли история
```

**Если `git remote -v` что-то показывает** — код уже в каком-то git-хостинге (GitLab, Bitbucket, собственный Gitea). Пришлите адрес, дальше решим.

**Если это git-репозиторий без remote** — достаточно один раз запушить в GitHub:

```bash
# создать пустой приватный репозиторий vargov3-spec/vargov-site на github.com, затем:
git remote add origin https://github.com/vargov3-spec/vargov-site.git
git push -u origin main
```

**Если это не git-репозиторий вообще** (просто папка с файлами) — сначала инициализировать. Важно: `.gitignore` должен исключать `node_modules`, `.next` и файлы с паролями (`.env*`), иначе в репозиторий утекут секреты.

## Если доступа к серверу нет у вас

Сайт кто-то делал и разворачивал. У этого человека или подрядчика код почти наверняка есть локально. Достаточно попросить: «запушить репозиторий сайта в GitHub на аккаунт vargov3-spec, приватным» — это разовая операция на несколько минут.
